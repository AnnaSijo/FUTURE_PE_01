# AI Website Copy Generator for Local Businesses

## Project Overview

This project demonstrates how Prompt Engineering and AI website development tools can be used to generate professional website content for local businesses.

The framework is designed to generate:

- Homepage Copy
- Service Descriptions
- Call-To-Action (CTA) Sections
- Business-Focused Website Content

The system can be adapted for:

- Cafes
- Restaurants
- Salons
- Clinics
- Agencies
- Coaching Centers
- Small Businesses

---

## Demonstration Business

### Koda Café Restaurant

Location: Marathakkara, Thrissur, Kerala

Industry: Café & Multi-Cuisine Restaurant

---

## Objective

To design a reusable prompt framework capable of generating website-ready content for local businesses using AI.
